# 11 当前项目分区

本手表固件按 **8MB 主 SPI NOR**、**OpenCPU + VoLTE + 单卡** 切分区。源文件：

```
components/hal/config/8910/partinfo_8910_8m_opencpu.json
```

`build_all.sh` 在 `VOLTE` + `SINGLESIM`（默认产品入口）时把环境变量 `partitionfile` 指到这份 JSON。CMake 再写成 `partinfo.bin`，打进 `*.pac`。

> 模组：`EC600UCN_LB`  
> target：`8915DM_cat1_open`  
> 芯片 XIP 基址：`0x60000000`（物理偏移 = 映射地址 − `0x60000000`）  
> 片容量：`0x800000` = **8MB**（和 W25Q64 一类 8MB 片对齐；16MB 见文末）

产物里的 `prepack/partinfo.bin` 就是这份表的二进制。pac / APPIMG 见 [10_编译产物说明.md](10_编译产物说明.md)。

---

## 1. 整片怎么切

从片头 `0x000000` 到片尾 `0x800000`，中间没有空洞：

```
物理偏移        大小         映射地址           名字        进哪个包
──────────      ──────       ──────────         ────        ────────
0x000000        64KB         0x60000000         BOOT        底包
0x010000        2.25MB       0x60010000         APP         底包（AP 内核）
0x250000        2MB          0x60250000         APPIMG      merge 后是本次 UI
0x450000        320KB        0x60450000         FSYS  "/"   文件系统
0x4A0000        3.25MB       0x604A0000         FMOD  "/modem"
0x7E0000        128KB        0x607E0000         FFAC  "/factory"
0x800000        ——           ——                 片尾
```

```
0x000000                                                         0x800000
|<--BOOT-->|<-------- APP -------->|<---- APPIMG ---->|<FSYS>|<----- FMOD ----->|<FFAC>|
  64KB           2.25MB                   2MB          320KB       3.25MB         128KB
```

加起来：`0x10000 + 0x240000 + 0x200000 + 0x50000 + 0x340000 + 0x20000 = 0x800000`。

FDL1 / FDL2 **不占 Flash 分区**，下载时下到 RAM，写完片就结束。

---

## 2. 各区含义

JSON 里分两类描述：

- **`macros`**：boot / AP / APPIMG / 三块 FS 的 **绝对映射地址和长度**（给链接脚本、CMake `#cmakedefine`）
- **`descriptions`**：FBD2 块设备 + SFFS 挂载（给文件系统和 `partinfo.bin`）

FBD2 只列了 FSYS / FMOD / FFAC。BOOT、APP、APPIMG 不走块设备，由 `macros` 和链接脚本直接定死。

| 区 | JSON 字段 | 物理 | 映射 | 擦块 | 干什么 |
|----|-----------|------|------|------|--------|
| BOOT | `CONFIG_BOOT_FLASH_*` | `0x000000` / 64KB | `0x60000000` | — | 一级/二级 boot 镜像 |
| APP | `CONFIG_APP_FLASH_*` | `0x010000` / `0x240000` | `0x60010000` | — | AP 内核：`8915DM_cat1_open.img` |
| APPIMG | `CONFIG_APPIMG_FLASH_*` | `0x250000` / `0x200000` | `0x60250000` | — | OpenCPU 应用：`C51_APP.img`（LVGL UI） |
| FSYS | offset `0x450000` size `0x50000` | 320KB | `0x60450000` | 32KB | SFFS 挂 `/`，`reserve_block=128` |
| FMOD | offset `0x4a0000` size `0x340000` | 3.25MB | `0x604a0000` | 64KB | SFFS 挂 `/modem`，应用只读 |
| FFAC | offset `0x7e0000` size `0x20000` | 128KB | `0x607e0000` | 4KB | SFFS 挂 `/factory`，boot/应用都只读；`bootloader_ignore` |

挂载点宏：

| 宏 | 值 |
|----|-----|
| `CONFIG_FS_SYS_MOUNT_POINT` | `/` |
| `CONFIG_FS_MODEM_MOUNT_POINT` | `/modem` |
| `CONFIG_FS_FACTORY_MOUNT_POINT` | `/factory` |
| `CONFIG_FS_AP_NVM_DIR` | `/nvm` |
| `CONFIG_FS_MODEM_NVM_DIR` | `/modemnvm` |
| `CONFIG_FS_FOTA_DATA_DIR` | `/fota` |

`flash: SFL1` = 主 SPI NOR（不是外挂 EXT）。

`target.config` 里 `CONFIG_APPIMG_LOAD_FLASH=y`：应用从 Flash 的 APPIMG 区 XIP/加载，不是从文件再搬。

## 3. 和产物、下载槽的对应

| 分区 | 产物文件 | pac 槽（概念） |
|------|----------|----------------|
| BOOT | `prepack/boot.img`、`boot2.img` | BOOT / BOOT2 |
| APP | `8915DM_cat1_open.img` | AP |
| APPIMG | `app/C51_APP.img` | APPIMG（`pacmerge` 替换的就是它） |
| FMOD 内容 | `cat1_UIS8915DM_BB_RF_SS_cus.img` + nvitem | PS / NV（modem 镜像落到 modem 文件系统侧） |
| 整张表 | `prepack/partinfo.bin` | 分区表 |

`C51.pac` 带 BOOT+APP+（空/旧）APPIMG+FS+modem。  
`C51_merge.pac` 用本次 `C51_APP.pac` 盖掉 APPIMG。

APPIMG 只有 **2MB**。UI 资源、字体再涨，先看 `C51_APP.img`（约 1.6MB）还剩多少，满了要裁资源或改分区（会牵动后面 FSYS 起点）。

---

## 4. 脚本怎么选到这份表

`build_all.sh` 按 VoLTE / 双卡 / 外挂改文件名，都在 `components/hal/config/8910/`：

| 组合 | JSON | 和本项目的差别 |
|------|------|----------------|
| **VOLTE + 单卡（当前）** | `partinfo_8910_8m_opencpu.json` | 上文这张 |
| VOLTE + 双卡 | `partinfo_8910_8m_opencpu_ds.json` | APPIMG 缩到 `0xD0000`（832KB），FSYS 提到 `0x150000`，FMOD 提到 `0x370000` |
| NOVOLTE + 单卡 | `partinfo_8910_8m_opencpu_novolte.json` | modem 区不同，AP RAM 也换成 `0x980000/0x680000` |
| 再加 `EXTFLASH` | 文件名加 `_extflash` | 外挂片另切，主片 SFL1 布局仍按 8M 那套变体 |

换组合必须整包重下，分区表和镜像一起变，不能只下 APP。

---

## 5. 和 16MB 片的关系

板子若换成 W25Q128JV（16MB），**当前这份 JSON 仍然只声明 8MB**。多出来的 8MB 不会自动进 FSYS/APPIMG，等于闲置。

要吃满 16MB：新写/改一份 `partinfo`（可参考仓库里的 `partinfo_8910_16m*.json`，那不是 OpenCPU+VoLTE 现成表，不能直接换），并改：

- `CONFIG_FS_*` / `CONFIG_APPIMG_*` 宏
- `build_all.sh` 的 `partitionfile`
- 下载包与预置资源地址

驱动侧怎么认 16MB 片见 [08_W25Q128JV适配说明.md](08_W25Q128JV适配说明.md)。**加 CSV 行 ≠ 分区变大。**

---

## 6. 改分区时注意

1. 三块代码区（BOOT/APP/APPIMG）和后面 FS 必须首尾相接，总长 ≤ 片容量。  
2. 改 APP / APPIMG 大小后要重链 AP 和应用，不能只改 JSON。  
3. FSYS `erase_block=0x8000`（32KB），FMOD `0x10000`（64KB），FFAC `0x1000`（4KB），和 NOR 擦除粒度对齐。  
4. FFAC 只读，别当用户盘写。  
5. 改过分区必须下 **merge 整包**，不要只下 `C51_APP.pac`。

---

## 7. 一句话

当前手表是 **8MB NOR 上的 OpenCPU 单卡 VoLTE 表**：64KB boot + 2.25MB 内核 + **2MB 应用** + 320KB 根文件系统 + 3.25MB modem 文件系统 + 128KB 工厂区。整机烧 `8915DM_cat1_open_C51_merge.pac` 才能把这次 UI 写进 APPIMG。客户怎么改应用见 [12_客户开发说明.md](12_客户开发说明.md)。RAM 划分见 [13_内存划分说明.md](13_内存划分说明.md)。
