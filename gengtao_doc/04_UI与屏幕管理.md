# 04 UI 与屏幕管理

`lv_widgets` 是手表界面，只在 `QL_APP_FEATURE_LVGL_V7` 时编译，链接 `lvgl` + `function`。

## 1. 入口 `main_screen()`

```c
void main_screen(void) {
    lv_i18n_init(lv_i18n_language_pack);
    lv_i18n_set_locale("zh-CN");
    main_screen_1();   // 创建并进入 IDLE 屏
}
```

PNG 解码 `lv_png_init()` 目前注释掉。图片以 C 数组形式编进 `assets/output/`。

## 2. 页面栈（screen stack）

全屏业务界面由 `screen_manager.c` 按**页面栈**管理。代码里链表头就叫 `screen_stack`：新开一页 push，返回 pop，IDLE 是栈底。实现是双向链表，深度上限 `MAX_SCREEN_HISTORY = 10`。

每页四个回调：`init` / `deinit` / `entry` / `exit`。`entry` 里通常 `lv_scr_load()`。

| API | 栈语义 | 作用 |
|-----|--------|------|
| `ic_screen_create(index, cb)` | push | exit 当前页；同 index 已在栈上则不再创建，否则 malloc + `init` |
| `ic_screen_entry(index)` | 调到前台 | exit 当前，调用目标 `entry`；若节点已在栈中会摘到栈顶 |
| `ic_screen_goback()` | pop | `exit` + `deinit` 当前，`entry` 上一页；IDLE 无法再返回 |
| `ic_screen_goto_idle()` | 清栈回根 | 销毁全部节点后重新 `main_screen_1()` |
| `ic_screen_close_active()` | pop | 等于 `goback` |

典型路径：

```
IDLE → 主菜单 → 通讯录 → 拨号
              ← goback ←
```

和纯栈不完全一样的两点：

- 按 `screen_index` **去重**，同一页不会压两份
- `entry` 可以把中间已有节点**挪到栈顶**，更像「历史记录 + 调到前台」

**抽屉 / 信息卡不算独立页面，不进栈。** 下拉控制中心、右拉信息卡、上拉消息都是 IDLE 这一页上的图层，只做位移，不走 `create/goback`。

页面索引（`screen_index_enum`）：

| 枚举 | 含义 |
|------|------|
| `SCREEN_INDEX_IDLE` | 待机表盘 |
| `SCREEN_INDEX_MAINMENU` | 主菜单 |
| `SCREEN_RECENT_CALLOG` / `SCREEN_MISSED_CALLLOG` | 通话记录 |
| `SCREEN_ALARM_CLOCK` / `_ADD` / `_FRE` | 闹钟 |
| `SCREEN_SELECT_PHOBEBOOK_OR_DIAL` | 通讯录或拨号选择 |
| `SCREEN_DIAL` | 拨号盘 |
| `SCREEN_CALLING` | 呼叫中 |
| `SCREEN_PB_LIST` | 通讯录列表 |

## 3. 待机桌面（IDLE 页内图层，不进页面栈）

`main_screen_init()` 在 IDLE 这一个全屏 root 上叠多层：

```
root 128x128 黑底
 ├─ clockface          表盘（当前强制用 clock_table[1]）
 ├─ control_center     下拉抽屉
 ├─ infocard           右拉信息卡
 ├─ message_center     上拉消息
 └─ mainmenu           主菜单（从下方/侧滑进入）
```

时钟每 1s 一次 `lv_task`：`CLOCK_UPDATE_INTERVAL = 1000`。

滑动方向在 `main_screen_event_cb` / `mainmenu_screen_event_cb` 里用按下点差判断，不是 LVGL 内置 gesture API。

## 4. 表盘

`clockface_table.c` 的 `clock_table[]`：

- `[0]` 数字表盘 DIGITAL1
- `[1]` 当前启用（`main_screen.c` 里 `else if(1)`）
- `[2]` 第三套

表盘描述 `clockface_t`：背景图、时分秒针或数字图位置。资源是 `IMG_CLOCKFACE_*` 的 LVGL 图数组。

改表盘：改 `clock_table` + 用 `image_gen.py` 重新导出图片。

## 5. 主菜单与业务屏

主菜单图标（`CMakeLists.txt` 已编进固件）：

- 电话簿 / 设置 / 学生卡 / 温度 / 工具 / 天气

已看到实现的子模块：

| 模块 | 文件 |
|------|------|
| 通讯录 / 拨号 | `mainmenu/src/ic_mainmenu_phonebook.c` |
| 通话记录 | `mainmenu/src/ic_mainmenu_calllog.c` |

## 6. 字体与 i18n

- 默认主题字体：Montserrat 14（`lv_conf.h`）
- 中文：`fonts/opposans_14.c`，经 `iclv_font.c` 暴露
- i18n：`i18n/lv_i18n.c`，默认 `zh-CN`
- 语言宏：`config/language_config.h`

`title_bar.c` + `IMG_IDLE_BATTERY0~4`。RTC 走 `hal/src/ic_hal_rtc.c`（设备）或 `ic_hal_rtc_win32.c`（模拟器）。
