# 06 已知问题与后续工作

读代码时已经能确定的风险，后续改 LVGL 建议先处理或至少心里有数。

## 1. 通话事件会干掉 GUI 线程

`lvgl_demo.c` 主循环：

```c
if (QL_VC_INIT_OK_IND <= event.id && event.id <= QL_VC_CCWA_IND)
{
    ic_vc_call_event(event);
    break;   // ← 跳出 while(1)，任务自杀
}
```

来电/通话 URC 一旦进 GUI 队列，界面线程就结束，`lv_task_handler` 不再跑。这里大概率本意是 `continue`。改之前建议用日志确认是否真的会走到这个分支。

## 2. GUI 任务栈只有 4KB

`QL_Lvgl_TASK_STACK_SIZE 1024*4`。LVGL 刷新 + 多层控件 + 日志，4KB 很容易溢出。表现是随机花屏、重启、HardFault。加复杂页面时优先把栈加到 8~16KB 并看高水位。

## 3. 全屏缓冲且 buf1==buf2

128×128×2=32KB 还能接受。若升到 240×240，单缓冲约 112KB，双缓冲翻倍。`lv_disp_buf_init(buf, buf, ...)` 没有真正的双缓冲，flush 期间 CPU 不能同时画下一帧。花屏/撕裂时考虑：

- 两块独立 buffer
- 或按行数做 partial buffer（例如 20 行）降低 RAM

## 4. 触摸 `read_cb` 类型用错

`ctp_main.c`：

```c
static lv_indev_drv_t last_data = {0};   // 应该是 lv_indev_data_t
memcpy(data, &last_data, sizeof(lv_indev_data_t));
```

`lv_indev_drv_t` 比 `lv_indev_data_t` 大，能拷过去但语义不对，也容易把驱动结构当坐标用。滑动异常、点不准优先查这里。另外 `memcpy` 用的是**上一次**缓存，本次 pop 的结果要到下一轮才交给 LVGL，会有一帧延迟。

## 5. `lv_port` 容易看错

`lvgl7_lib/lv_port/lv_gui_main.c` 是 RDA 内核风格（`drvLcd` / `osiThread`），**当前 CMake 没编译**。设备上真正的移植是 `lvgl/lvgl_demo.c`。改 flush/keypad 不要改错文件。

## 6. V7 与 V6 入口不对称

非 V7 分支调用 `lvglAnimCreate`，但 `lvgl_demo.c` 没有这个函数（只在未编译的 `lv_port/lv_gui_example1.c` 里）。关掉 `QL_APP_FEATURE_LVGL_V7` 会链接失败。现在默认 V7，暂无影响。

## 7. 分辨率与屏驱可能不一致

GUI 写死 128×128，驱动仓库里同时有 240×320 / 240×240 panel。若硬件不是 ST7735S 128×128，会出现只显示一角、拉伸或花屏。改屏三件套：panel 驱动、`lv_gui_config.h`、UI 资源。

## 8. flush 日志太重

`prvDispFlush` 每次脏区都 `QL_LVGLDEMO_LOG`。30ms 刷新时 log 会拖慢刷屏。量产应关掉或改 verbose。

## 9. CMake 图片重复、CST716 空洞

- `IMG_IDLE_BATTERY4.c` 在 `lv_widgets/CMakeLists.txt` 写了三次
- `ctp` include 了 `cst716` 目录但没有源文件
- `factory_sensor.c`、`mainmenu_iwatch.c` 未进 `target_sources`，是否废弃未标明

## 10. 建议的后续切入顺序

按改动面从小到大：

1. **先能跑、能看 log**：确认 `QL_APP_FEATURE_LVGL_V7`、屏型号、触摸中断是否进 `ctp_interrupt_callback`
2. **修 GUI 循环 `break`、触摸 last_data 类型、任务栈**
3. **确认分辨率 / flush 矩形是否和 panel 一致**
4. **再改 UI**：新屏走 `ic_screen_create` + `entry`，不要在 GUI 线程外 `lv_obj_*`
5. **资源**：新图走 `image_gen.py`，并记得改 CMake
6. **模拟器**：桌面验证布局后再编设备

## 11. 调试时常用抓手

| 想确认 | 看哪里 |
|--------|--------|
| GUI 线程是否起来 | log tag `ql_LVGLDEMO`：`lvgl demo thread enter` |
| LCD 是否 init 成功 | 同上 `LCD init failed` |
| 有没有在刷 | `disp flush x1/y1/x2/y2` |
| 触摸中断 | log tag `CTP`：`ctp_interrupt_callback` |
| 按键 | `keypad last key` / `lvgl keymap` |
| 当前是哪块屏 | `screen_manager` 的 `screen_index_enum` |
| 表盘套数 | `main_screen.c` 里 `clock_table[n]` |
