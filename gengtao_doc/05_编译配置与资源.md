# 05 编译配置与资源

## 1. Feature 开关链

```
ql_target.cmake / projects/C56U_HM_SH8/ql_target.cmake
    CONFIG_QUEC_PROJECT_FEATURE_LCD = on
        ↓
ql_app_feature_config.cmake
    QL_APP_FEATURE_LCD     ON
    QL_APP_FEATURE_LVGL    ON
    QL_APP_FEATURE_LVGL_V7 ON
        ↓
CMakeLists.txt（ql-application）
    add lvgl7_lib, lv_widgets, lvgl
    始终 add ctp
```

应用头文件由 `ql_app_feature_config.h.in` 生成 `QL_APP_FEATURE_LCD` 等宏，`lvgl_demo.c` / `ql_init.c` 用这些宏编译期裁剪。

CTP 额外开关：

```
CONFIG_INCAR_APP_FEATURE_CTP
  └─ 等于 "BL6133" 时开 INCAR_APP_FEATURE_CTP_BL6133
```

当前 `ql_target.cmake` **没有**定义 `CONFIG_INCAR_APP_FEATURE_CTP`。CTP 库仍被 `add_subdirectory(ctp)` 编进去，运行时 `ctp_init()` 无条件调用。开关只影响 cmake option，和实际源文件包含关系要再核对 `ctp` 内部宏。

## 2. LVGL 关键 `lv_conf.h`（v7）

| 宏 | 当前值 | 含义 |
|----|--------|------|
| `LV_HOR_RES_MAX/VER_RES_MAX` | 128 | 最大分辨率 |
| `LV_COLOR_DEPTH` | 16 | RGB565 |
| `LV_MEM_CUSTOM` | 1 | 走 libc `malloc/free` |
| `LV_DISP_DEF_REFR_PERIOD` | 30 ms | 刷新周期 |
| `LV_INDEV_DEF_READ_PERIOD` | 30 ms | 输入轮询 |
| `LV_TICK_CUSTOM` | 1 | `ql_rtc_up_time_ms()` |
| `LV_USE_LOG` | 1 | 打开日志 |
| `LV_USE_FILESYSTEM` | 1 | 文件系统（图片多数仍是 C 数组） |
| `LV_THEME_DEFAULT_INIT` | material light | 默认主题 |
| `LV_FONT_MONTSERRAT_14` | 1 | 默认字体 |
| `LV_FONT_MONTSERRAT_30` | 1 | 大号数字 |

CMake 把 `lvgl7_lib` 编成静态库 `lvgl`，输出到 `out_lib_dir`。`ql_app_lvgl` 链接 `lvgl`、`lv_widgets`、`ctp`。

## 3. 图片资源流水线

1. 源图：`lv_widgets/assets/images/`
2. CSV 清单（给脚本）
3. 根目录 `image_gen.py` 调 `tools/lvgl/lv_utils/img_conv_core.php`
4. 生成 `lv_widgets/assets/output/IMG_*.c` + `image_id_list.c` + `image_declare.h`
5. 必须把新 `.c` 加进 `lv_widgets/CMakeLists.txt` 才会进固件

Windows 一键：`resgen.bat`。PHP 运行时在 `tools/php/`（Windows）或 `tools/incar/php/`。

色格式常用：`true_color` / `true_color_alpha`（见 `image_gen.py -c`）。

## 4. 字体

- 内置：`lvgl7_lib` 已编译多档 Montserrat、Roboto
- 项目中文：`tools/lvgl/lv_font_conv` 转 C 数组 → `lv_widgets/fonts/`
- 规格说明：`tools/lvgl/lv_font_conv/doc/font_spec.md`

## 5. i18n

`tools/lvgl/lv_i18n` 从源码抽 `_()` 字符串，生成 `lv_widgets/i18n/lv_i18n.c`。

## 6. 模拟器

`simulator/lvgl/LVGL.Simulator.sln`（Visual Studio 2019，Win32drv）。

`LVGL.Simulator.c` 已改成和设备同一入口：

```c
lv_init();
lv_win32_init(..., LV_HOR_RES_MAX, LV_VER_RES_MAX, ...);
main_screen();
ic_main_entry();
```

PC 上改表盘/菜单可以先在模拟器看，再编设备。HAL RTC 有 `ic_hal_rtc_win32.c` 分支。

注意：模拟器自带一份 LVGL 7 树，和 `lvgl7_lib` 是两份拷贝，改 `lv_conf.h` 要两边一起看。
